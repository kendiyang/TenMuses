================================================================================
                          核心功能说明
================================================================================

【功能 1: 从数据库读取配置】
- ConfigService.get_openai_config(db_session) 返回 API Key 和 Base URL
- 自动解密存储的加密密钥
- 支持回退到环境变量

【功能 2: 加密存储】
- API 密钥使用 ENCRYPTION_KEY 加密
- 自动在保存时加密，读取时解密
- 数据库中永远不存储明文密钥

【功能 3: 动态管理】
- 无需重启应用即可更新配置
- 通过 API 保存新密钥
- 应用立即使用新配置

【功能 4: 多提供商支持】
- OpenAI
- Anthropic
- 可扩展支持其他提供商

【功能 5: 优先级系统】
- 多个配置时自动选择优先级最高的
- Priority 数字越小优先级越高
- 支持通过 API 调整优先级

================================================================================
                            API 端点
================================================================================

GET /api/v1/config/llm/providers
  列出所有 LLM 提供商配置

GET /api/v1/config/llm/providers/{provider}
  获取特定提供商的配置（如 openai）

GET /api/v1/config/llm/openai
  获取 OpenAI 配置（不显示密钥）

GET /api/v1/config/llm/anthropic
  获取 Anthropic 配置（不显示密钥）

POST /api/v1/config/llm/providers
  创建或更新提供商配置

PATCH /api/v1/config/llm/providers/{provider}/toggle
  激活或停用提供商

================================================================================
                          安全特性
================================================================================

✅ 加密存储
   - API 密钥在数据库中被 AES-256 加密
   - 只在内存中以明文形式存在

✅ JWT 认证
   - 所有配置 API 需要有效的 JWT token
   - 防止未授权访问

✅ 安全日志
   - API 密钥不会在日志中显示
   - 只记录配置操作，不记录密钥内容

✅ 权限控制
   - 基于用户的访问控制
   - 支持细粒度权限管理

================================================================================
                          数据库架构
================================================================================

表名: llm_configs

字段说明:
  id                  UUID        配置唯一ID
  provider            VARCHAR     提供商名称 (openai, anthropic)
  model_name          VARCHAR     模型名称 (gpt-4-turbo-preview)
  api_key_encrypted   VARCHAR     加密的 API 密钥
  base_url            VARCHAR     自定义 Base URL (可选)
  display_name        VARCHAR     UI 显示名称
  is_active           BOOLEAN     是否激活
  priority            INTEGER     优先级（低数字=高优先级）
  description         VARCHAR     描述
  created_at          TIMESTAMP   创建时间
  updated_at          TIMESTAMP   更新时间

================================================================================
                        工作流程图
================================================================================

应用启动
    ↓
需要 OpenAI 配置
    ↓
调用 ConfigService.get_openai_config(db_session)
    ↓
1. 查询 llm_configs 表
    ↓
2. 找到 provider='openai' 的配置？
    ├─ 是 → 解密并返回配置 ✓
    └─ 否 → 检查 use_env_fallback
            ├─ True  → 查找环境变量 → 返回 ✓
            └─ False → 返回 {api_key: None, base_url: None}

                        问题排除速查

❌ "OpenAI configuration not found"
   ✓ 解决: bash setup-llm-config.sh

   ✓ 解决: 检查数据库连接 & ENCRYPTION_KEY

   ✓ 解决: 确保使用了有效的 Bearer token

================================================================================
                        环境变量配置
================================================================================

关键变量:

DATABASE_URL
  数据库连接字符串
  例: postgresql://user:pass@localhost/tenmuses

ENCRYPTION_KEY  
  用于加密 API 密钥的密钥（32 字节）
  例: 0123456789abcdef0123456789abcdef

OPENAI_API_KEY (可选，回退用)
  OpenAI API 密钥
  例: sk-...

OPENAI_BASE_URL (可选，回退用)
  OpenAI 自定义 Base URL
  例: https://api.openai.com/v1
